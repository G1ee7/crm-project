# Склад

Демонстрационный складской SaaS для малого бизнеса Казахстана. Каталог, четыре складских документа, движения и остатки работают с Cloudflare D1.

## Запуск

```bash
npm install
npm run dev
npm run dev:api
```

Веб-приложение работает на `http://localhost:5173`, API — на `http://localhost:8787`.
В D1 хранятся товары, категории, склады, штрихкоды, документы прихода, расхода, списания и перемещения, журнал движений, остатки и аудит. Продажи и прибыль на главной странице пока демонстрационные.

Для локальной D1 выполните `npm run db:migrate:local`. Seed идемпотентен: повторный запуск не создаёт дубли и не переписывает изменённые товары. Локальный Worker должен работать на порту 8787, Vite проксирует к нему `/api`.

Worker раздаёт production-сборку SPA из `apps/web/dist`; пути `/api/*` обрабатывает Hono. D1 привязана в `apps/api/wrangler.jsonc`. Для развёртывания сначала примените миграции и seed командами `npx wrangler d1 migrations apply warehouse-demo --remote` и `npx wrangler d1 execute warehouse-demo --remote --file=seed.sql` из `apps/api`, затем выполните `npm run deploy`. Хранилище R2 понадобится на следующих этапах; пока оно не подключено.

API: `GET/POST /api/categories`, `PATCH/DELETE /api/categories/:id`, `GET/POST /api/warehouses`, `GET/PATCH /api/warehouses/:id`, `GET/POST /api/products`, `GET/PATCH/DELETE /api/products/:id`, `GET /api/inventory`, `GET/POST /api/suppliers`. Для каждого из `/api/receipts`, `/api/issues`, `/api/writeoffs`, `/api/transfers` доступны список, карточка, создание, изменение черновика, `POST /:id/post` и `POST /:id/cancel`. `GET /api/stock-movements` отдаёт журнал с серверной фильтрацией и пагинацией. Все запросы используют серверный контекст организации `demo`. Цены передаются целыми числами в тиынах (1 ₸ = 100 тиын).

Проведение документа выполняется одной транзакцией `D1.batch()`. Оно создаёт запись о финализации, движения, меняет статус и пишет аудит. Триггер после вставки движения обновляет `stock_balances`; триггеры баланса запрещают количество меньше резерва и откатывают весь batch при нехватке товара. Движения нельзя обновить или удалить. Уникальная финализация и ревизия черновика блокируют повторное и конкурентное проведение. Начальные остатки представлены историческими приходами `OPEN-*`.

Проверки: `npm run typecheck`, `npm run lint`, `npm run build`, `npm run test:api` при запущенном локальном Worker. `npm run test:api` проверяет проведение, повтор, конкурентный расход, откат перемещения и сверяет остатки с журналом по всем товарам и складам демо-организации. `npm run measure:api` измеряет локальные ответы основных списков.
